---
title: Server SDKs
description: Choose a source SDK for your language or integrate directly over HTTPS.
---

The server SDKs use your assigned API origin, merchant ID and a server-side API key. Ask your integration contact for source access. The [HTTP quickstart](/quickstart) works without installing an SDK.

| Language | Requirements | Where to start |
| --- | --- | --- |
| Node.js / TypeScript | Node 20+, ESM or CommonJS | [Configure a Node client and create a sale](/sdks/node) |
| PHP | 64-bit PHP 8.1+, PSR-18 transport and PSR-17 factories | [Configure PHP and look up an order](/sdks/php) |
| Python | Python 3.11+, sync or asyncio | [Read a transaction with Python](/sdks/python) |

The [OpenAPI contract](/openapi.json) covers additional operations. For browser integrations, use the [checkout widget](/js-widget) or [embedded cashier](/cashier). Keep merchant API keys on your server.
